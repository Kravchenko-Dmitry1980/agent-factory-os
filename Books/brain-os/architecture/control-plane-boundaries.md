# Control Plane Boundaries

## Внутри Brain OS

task classification, cognitive routing, memory **control** (not storage), policy selection, reasoning orchestration, execution supervision, evaluation, safety, adaptation, trace

## Вне Brain OS

- UI продукта
- LLM providers
- Vector DB (хранение)
- Sandbox renderer / game engine
- External tools (MCP/API) — вызываются через product/runtime bridges

## Принцип

Control plane **координирует**, не **заменяет** planes.

## Maturity

production-relevant
