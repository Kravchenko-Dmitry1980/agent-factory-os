# Почему это ещё не ощущается как продукт

**Дата:** 2026-05-26  
**Аудитория:** оператор, Дмитрий, стажёры

---

## Простой ответ

Система **работает**, но **не ощущается как продукт**, потому что взаимодействие — это **PowerShell + фиксированные сценарии + сырой trace**, а не привычный пользовательский опыт.

---

## Конкретные причины

| Причина | Что чувствует оператор |
|---------|------------------------|
| **Нет free-form input** | Нельзя написать «сделай review этого текста» |
| **Сценарии predefined** | Нужно знать имя `--scenario happy` |
| **Вывод = terminal trace** | Много технических строк, мало «итога для человека» |
| **Нет chat interface** | Не похоже на ChatGPT / Cursor chat |
| **Нет approval button** | Approval «магически» в сценарии |
| **Нет visual status** | Нет зелёной/красной лампочки «можно публиковать» |
| **Нет saved sessions** | Закрыл терминал — история ушла |
| **Нет history browser** | Нельзя посмотреть прошлые прогоны |
| **Нет agent card UI** | Карточка агента — markdown, не экран |
| **Нет workflow dashboard** | Нет «где задача, кто approved» |
| **Нет onboarding** | Нужно читать governance, чтобы понять что запускать |

---

## Но это ожидаемо

Текущая фаза проекта:

```text
verification-first lab
→ thin implementation
→ mock provider
→ real local provider
→ safety harness
→ second agent specs
→ hands-on report (сейчас)
```

**Product UX** сознательно **не** был целью Phase 3.1–3.5.

Документы, freeze, harness — **фундамент**. Hands-on — **первое «оживление»**. Product feeling — **следующий слой**.

---

## Когда появится «ощущение продукта»

Примерная лестница (не обязательно все сразу):

1. **Demo Runner** — один скрипт, меню сценариев, русское резюме после прогона
2. **Interactive CLI** — ввод своего текста задачи (с теми же gates)
3. **Readable report** — markdown/HTML summary вместо только raw trace
4. **Optional minimal UI** — позже, отдельная фаза с governance

См. [NEXT_PRACTICAL_STEPS_RU.md](NEXT_PRACTICAL_STEPS_RU.md).

---

## Что уже хорошо для lab-продукта

| Есть | Ценность |
|------|----------|
| Видимый agent loop | Можно учить и аудировать |
| Fail-closed | Плохие пути реально блокируются |
| Trace discipline | Совпадает с observability examples |
| Explicit real provider | Нет скрытого network call |

**Вывод:** это **сильная лаборатория**, слабый **consumer product**. Для текущего этапа — нормально.

---

## Аналогия

Сейчас — **испытательный стенд с осциллографом** (trace).

Продукт — **автомобиль с приборной панелью** (UI, input, history).

Стенд нужен **раньше**, чем серийная машина. Hands-on доказывает, что **мотор крутится**.
