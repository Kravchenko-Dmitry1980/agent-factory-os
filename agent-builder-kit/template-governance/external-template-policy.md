# External Template Policy

## Principle

External repos can **inspire structure**. External templates **cannot** be imported directly without governance review.

## Phase 2.10 Position

See `governance/phase-2-10/FINAL_PHASE_2_10_REPORT.md`:

- External agent repos = **research-only**
- No adoption into agent-os
- No template dumping into agent-builder-kit

## Allowed

- Read external README for ideas
- Compare gate patterns in governance notes
- Cite repo as research reference with date

## Forbidden

- Copy upstream template folders wholesale
- Import LangGraph / AutoGen / crew configs into kit
- Promote external repo to canonical template without review

## If External Template Desired Later

1. Write change proposal
2. Provenance + license check
3. Safety gate mapping
4. Evaluation scenarios
5. Lead approval
6. **Still no runtime in kit**

See [governance/no-external-template-import-policy.md](../governance/no-external-template-import-policy.md)
