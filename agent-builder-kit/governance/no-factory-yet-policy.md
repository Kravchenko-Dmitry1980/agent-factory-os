# No Factory Yet Policy

## Rule

This is **Agent Builder Kit v0.1**, not an **Agent Factory**.

## Factory implies (not present)

- Agent registry
- Template → code generator
- Ops dashboard
- Production eval pipeline embedded in kit
- Multi-template deploy system
- SaaS onboarding

## What v0.1 provides

- Design specifications
- Safety gate definitions
- One reference template (Review Assistant)
- Checklists for human review

## Naming

Use: **Builder Kit v0.1**  
Do not use: **Agent Factory**, **Agent Platform**, **Agent OS Runtime**

## Next factory work

Requires separate governance approval and phase plan — not Phase 3.0.
