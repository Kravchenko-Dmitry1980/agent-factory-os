# Builder Kit Boundaries

## In scope (v0.1)

- Markdown specifications
- Template documents
- Checklists
- Mermaid diagrams
- Governance policies for the kit
- One reference template: Review Assistant Agent

## Out of scope

- Runtime, CLI, API
- Code generator
- Agent factory
- Production deployment
- CV / digital twin / RAG / MCP
- External template import

## Principle

Define **how** a safe agent template should be designed — not **how** to run or generate agents.

## Enforcement

Violations → FAIL in [phase-3-template-review-checklist.md](../evaluation-checklists/phase-3-template-review-checklist.md)
