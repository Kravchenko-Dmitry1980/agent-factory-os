# Beginner Safe Policy

Defaults for interns and first-week operators.

---

## Always safe

- Read operator-playbooks and agent-os doctrine
- Run demos from runbooks
- Run evaluation smoke (read-only)
- Read observability examples
- Ask mentor when FAIL unexplained

---

## Ask first

- Edit any Python under prototypes/
- Edit integrations-real/
- Edit prototypes/shared/
- Add pip dependencies
- Promote content toward agent-os/

---

## Never solo (week 1)

- Shared gate changes
- New adapter creation
- Removing or bypassing approval/verification
- Adding GitHub Actions
- Framework extraction
