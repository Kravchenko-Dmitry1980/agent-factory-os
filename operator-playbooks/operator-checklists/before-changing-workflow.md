# Before Changing Workflow

- [ ] Change proposal drafted (`evolution/change-proposals/change-template.md`)
- [ ] Know which gate/invariant moves
- [ ] Baseline smoke run: `python evaluation/scripts/run_demo_smoke_checks.py`
- [ ] Read [../start-here/what-not-to-touch.md](../start-here/what-not-to-touch.md)
- [ ] Impact area identified (`evaluation/regression-matrix/change-impact-matrix.md`)
- [ ] Rollback plan ready ([../runbooks/rollback-after-failure.md](../runbooks/rollback-after-failure.md))
- [ ] Mentor/lead informed if intern or shared module touch

**Stop if:** change removes approval, verification, escalation, or audit events.
