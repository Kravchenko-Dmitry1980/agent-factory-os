# Типичные ошибки (RU)

Для каждой: **симптом → смысл → проверка → чего НЕ делать**.

---

## Неверная папка

| | |
|-|-|
| **Симптом** | `can't open file` / нет `minimal-demo.py` |
| **Смысл** | Терминал не в корне репозитория |
| **Проверить** | `cd C:\Dima\Projects\CURSOR\AGENT` |
| **НЕ делать** | Копировать скрипты в другую папку |

---

## Python не найден

| | |
|-|-|
| **Симптом** | `python` не является командой |
| **Смысл** | Python не в PATH |
| **Проверить** | `python --version` или `py --version` |
| **НЕ делать** | Устанавливать пакеты в случайный venv без документации |

---

## Ошибка пути

| | |
|-|-|
| **Симптом** | ModuleNotFoundError, wrong path |
| **Смысл** | Запуск не из корня или опечатка в пути |
| **Проверить** | Полный путь как в [CHEATSHEET.md](CHEATSHEET.md) |
| **НЕ делать** | Менять `PYTHONPATH` «чтобы заработало» |

---

## Demo падает

| | |
|-|-|
| **Симптом** | Traceback при `minimal-demo.py` |
| **Смысл** | Окружение или повреждённый файл (редко) |
| **Проверить** | Корень, версия Python; EN: `../troubleshooting/demo-does-not-run.md` |
| **НЕ делать** | Снимать gates в коде |

---

## Smoke check FAIL

| | |
|-|-|
| **Симптом** | `FAIL` в строке демо, `Summary: ... FAIL=1` |
| **Смысл** | Поведение демо не совпало с ожиданием evaluation |
| **Проверить** | Текст FAIL; был ли недавний change без proposal |
| **НЕ делать** | Ослаблять ожидания в скриптах evaluation |

## Trace check FAIL

| | |
|-|-|
