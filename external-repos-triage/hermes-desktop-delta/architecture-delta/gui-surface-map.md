# GUI Surface Map — Future Agent-OS Operator Console

Mapping potential screens. Hermes Desktop has analogues for many — we adapt with governance-first lens.

| Screen | Description | Timing |
|--------|-------------|--------|
| **Agent Templates** | Frozen spec status, version, sign-off links | LATER |
| **Implementations** | Derived impls (e.g. review-assistant-thin v0.2) | LATER |
| **Evaluation Runs** | Script results, PASS/FAIL history | LATER |
| **Trace Viewer** | Parsed events, decision, delivery flag | LATER |
| **Approval Queue** | Pending human approvals (read + action) | LATER |
| **Memory Boundaries** | What may/cannot persist | MUCH_LATER |
| **Tools** | Allowed tools per template; enable/disable | MUCH_LATER |
| **Skills** | Installed skills review; supply-chain status | MUCH_LATER |
| **Provider Config** | Single-provider boundary config (not router) | MUCH_LATER |
| **Governance Status** | Phase, freeze, change lock, verdicts | LATER |
| **Rollback / Freeze Records** | Version history, rollback triggers | LATER |
| **Research Backlog** | external-repos-triage summaries | NOW (markdown) |
| **Chat (primary)** | Hermes-style main screen | NEVER as default — not our product |
| **Schedules / Cron** | Unattended jobs | NEVER (or MUCH_LATER with heavy gates) |
| **Gateways (Telegram, …)** | Outbound messaging | NEVER for Agent-OS Lab core |
| **Skill Installer** | One-click skill add | NEVER without supply-chain phase |
| **Persona / SOUL editor** | Personality files | NEVER — conflicts template governance |
| **3D Office / Kanban** | Hermes extras | NEVER |
| **Remote mode** | Connect to remote agent server | NEVER for lab default |
| **Desktop installer / updater** | Electron distribution | NEVER in Phase 3–4 |
