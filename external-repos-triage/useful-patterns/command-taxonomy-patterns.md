# Pattern: Command Taxonomy

| Field | Value |
|-------|-------|
| **Source repo** | SuperClaude_Framework |

## Why Useful

Operators need ≤10 commands, not 30 — taxonomy shows how to group.

## How It Could Help Later

## Why Not Adopt Now

Persona/mode explosion risk.

## Safe Future Use
