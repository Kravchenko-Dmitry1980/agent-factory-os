# Dangerous Pattern: Template Dumping

| Field | Value |
|-------|-------|
| **Source** | claude-code-templates, scientific-agent-skills (`npx skills add`) |
| **Why tempting** | One command full stack |
| **Why dangerous** | Unreviewed MCP/hooks/skills |
| **Early signals** | `--yes` installs, 100+ components |
| **Mitigation** | install only what you need; provenance |
| **Phase 3.0** | **One** Review Assistant spec only |
