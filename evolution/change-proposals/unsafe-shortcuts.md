# Unsafe Shortcuts

Forbidden shortcuts during evolution — even under deadline pressure.

| Shortcut | Drift type |
|----------|------------|
| "Skip human for internal only" | autonomy drift |
| "Merge demos into shared framework" | framework drift |
| "Remove escalation to unblock demo" | governance erosion |
| "Trust critic on staging" | verification drift |
| "Increase MAX_RETRIES to 10 temporarily" | retry storm |
| "Add CI deploy before gate review" | platform drift |
| "Feature flag auto-approve" | hidden autonomy |
| "Delete failure-modes.md — obvious" | observability loss |

## Response

1. Stop merge
2. Rollback if already merged
3. Record in [examples/](../examples/) as anti-example

## Mantra

**Rollback before complexity.**
