# Governance Gates (Change)

Safe modification boundaries during evolution.

## Required Gates

| Gate | Purpose |
|------|---------|
| Promotion gate | agent-os / canonical changes |
| Approval gate | HITL boundaries |
| Verification gate | evidence before action |
| Escalation gate | ceiling + human path |
| Rollback gate | reversal plan exists |
| Observability gate | events/traces updated |
