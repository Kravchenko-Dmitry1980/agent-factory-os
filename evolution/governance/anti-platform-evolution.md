# Anti-Platform Evolution

Phase 2.4 must not become deployment or platform engineering.

## Forbidden Evolutions

- CI/CD pipeline as repo product
- GitOps manifests
- K8s rollout strategies
- Feature flag service
- Config orchestration (Helm, Terraform for demos)
- Migration engine for workflow state
- Universal change ticket system

## Allowed

- Markdown change proposals
- Manual git revert
- Local demo validation stages
- Phase governance reviews

## Test

> Did we add a workflow to **deploy** or to **decide safely**?

Deploy → out of scope.
