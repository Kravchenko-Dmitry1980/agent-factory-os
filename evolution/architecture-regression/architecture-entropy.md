# Architecture Entropy

Second law for governed repos: without effort, order → chaos.

## Entropy Sources

- New features without new failure scenarios
- Shared modules "for DRY"
- Real adapters without mock parity
- Observability renamed without mapping
- Skipped phase reviews

## Entropy Reduction (Allowed Work)

- Change proposals
- Trace examples
- Gate checklists
- Rollback drills
- Drift reviews

## Entropy Increase (Forbidden)

- Universal workflow engine
- CI/CD platform in-repo
- Metrics without canonical events

## Balance

Phases 2.0–2.4 **document** order — maintenance is human discipline.
