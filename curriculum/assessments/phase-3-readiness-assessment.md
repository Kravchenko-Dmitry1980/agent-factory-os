# Phase 3 Readiness Assessment

Gate before starting **Agent Builder Kit** — not a graduation certificate.

## Required Competencies

Student (or team) must demonstrate **all**:

| # | Competency | Evidence |
|---|------------|----------|
| 1 | Run demos | Smoke PASS; narrate happy + fail demo |
| 2 | Read trace | Exercise-read-trace pass |
| 3 | Explain fail-closed | Own words + demo example |
| 4 | Detect unsafe autonomy | Red flag exercises pass |
| 5 | Run evaluation | Three scripts executed and explained |
| 6 | Write change proposal | Exercise or real proposal reviewed |
| 7 | Decide rollback | Scenario exercise pass |
| 8 | Understand platform drift | Drift exercise pass |

Full criteria: [../methodology/phase-3-entry-criteria.md](../methodology/phase-3-entry-criteria.md)

## Written Questions

All ten core questions plus:

1. What is Agent Builder Kit (expected scope)?
2. What is explicitly NOT Phase 3?
3. Why digital twin factory waits?

## Practical Tasks

1. Mentor-observed: 30-min workshop facilitation by student (optional stretch)
2. Team smoke green + trace walkthrough escalation example
3. Signed checklist from [../governance/phase-3-gate-policy.md](../governance/phase-3-gate-policy.md)

## Red Flag Recognition

*"Phase 2 done — start building agent factory next sprint."*

**Expected:** verify entry criteria; likely not ready if assessments incomplete.

## Explain In Your Own Words

What did you learn that prevents building the wrong platform?

## Pass Criteria

- All 8 competencies evidenced
- Lead sign-off on phase-3-gate-policy checklist
- No open critical gaps in operator or developer assessments

## Fail Criteria

Any competency missing; hype-driven Phase 3 push; cannot explain gates without docs.

**Not ready is OK** — continue curriculum modules 8–12.
