# Project Lead Assessment

## Written Questions

Core ten questions at conceptual level — focus on judgment, not commands.

Additional:

1. What is this repo NOT (stakeholder pitch)?
2. What is promotion vs adding a markdown file?
3. When should team start Phase 3?
4. What must remain human-operated?

## Practical Tasks

1. Review a sample change proposal (mentor provides) — list three review questions you would ask
2. Interpret summarize_evaluation_status output at high level
3. Assign correct learning track to three fictional roles (intern, dev, cursor user)

## Red Flag Recognition

Team proposes: *"Ship prototypes as internal platform Q3."*

**Expected:** platform drift; redirect to curriculum method; Phase 3 criteria first.

## Explain In Your Own Words

Explain why evaluation is local and not CI — to engineering manager in 2 minutes.

## Pass Criteria

- Stakeholder pitch accurate (learning lab, not production)
- Phase 3 gated by entry criteria doc
- Identifies platform proposal as drift
- Can delegate onboarding to curriculum + operator-playbooks

## Fail Criteria

Calls repo production-ready platform; skips governance on promotion; no Phase 3 gate awareness.
