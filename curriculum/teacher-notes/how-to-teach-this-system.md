# How to Teach This System

## Principles

1. **Demo before lecture** — show audit, then name the gate
2. **Fail paths required** — happy path alone teaches optimism bias
3. **One idea per hour** — fail-closed is one session, not a bullet
4. **No hype words** — avoid "autonomous", "AGI", "replace humans"
5. **Use repository artifacts** — doctrine + trace + demo, not slides-only

## Session Structure

```
Hook (demo) → Name concept → Read trace → Exercise → Checkpoint questions
```

## Materials Order

1. curriculum lesson (simple)
2. agent-os doctrine (deeper)
3. prototype demo (proof)
4. operator runbook (operations)

## Assessment

Use written + practical — never multiple-choice only.

## Common teacher mistakes

- Talking 90% of time
- Skipping bypass/ deny scenarios
- Promising Phase 3 date before criteria

See [common-student-misunderstandings.md](common-student-misunderstandings.md)
