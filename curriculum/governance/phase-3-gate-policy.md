# Phase 3 Gate Policy

Formal gate before Agent Builder Kit work begins.

---

## Gate owner

Project lead + architect (if assigned) sign checklist.

---

## Checklist

- [ ] All items in [../methodology/phase-3-entry-criteria.md](../methodology/phase-3-entry-criteria.md) evidenced
- [ ] [../assessments/phase-3-readiness-assessment.md](../assessments/phase-3-readiness-assessment.md) complete
- [ ] Team agrees Phase 3 scope document (future) excludes:
  - production cloud deploy
  - digital twin factory
  - autonomous swarm product
- [ ] Evaluation smoke PASS on branch starting Phase 3
- [ ] No unresolved critical governance regression

---

## If gate fails

Continue curriculum Levels 7–10; extend operator practice; **do not** start factory code.

---

## If gate passes

Phase 3 may begin with **Builder Kit** charter — still local-first, still governance-dominated.

Teaching hype or skipping criteria invalidates gate.

---

## Re-review trigger

Major team turnover or governance incident → re-run phase-3-readiness assessment.
