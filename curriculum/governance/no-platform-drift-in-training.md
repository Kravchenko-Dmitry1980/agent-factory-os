# No Platform Drift in Training

Students must not learn that **framework extraction** is the goal.

## Drift teaching mistakes

- Final project = "unify all demos"
- Grade on lines of framework code
- Praise shared orchestrator as maturity

## Correct capstone

- Run evaluation smoke PASS
- Write change proposal
- Read traces for all critical behaviors
- Identify drift in scenarios
