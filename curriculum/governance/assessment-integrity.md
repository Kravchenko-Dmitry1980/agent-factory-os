# Assessment Integrity

## Principles

1. **Open book** — docs and demos allowed; brain-only memorization not the goal
2. **Demonstrate** — practical tasks required, not MCQ only
3. **No cheating gates** — editing smoke script to pass fails integrity
4. **Mentor sign-off** — human judgment on explain-in-your-own-words
5. **Fail is learning** — retake after more modules, not shortcut

## Prohibited

- Certificate without practical demo
- Phase 3 sign-off without lead review
- Passing student who cannot run bypass demo

## Red flag on assessment

Student defines fail-closed correctly but approves removing approval in practice task → fail overall.

## Records

Local mentor notes optional — no LMS required in Phase 2.7.
