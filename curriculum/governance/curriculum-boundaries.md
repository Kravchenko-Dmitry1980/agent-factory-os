# Curriculum Boundaries

Phase 2.7 adds **teaching structure** — not new runtime.

## In scope

- Modules, lessons, exercises, assessments
- Workshops and teacher notes
- Methodology and Phase 3 **entry criteria** (not Phase 3 build)
- Links to existing demos and operator-playbooks

## Out of scope

- New Python/scripts/automation
- Agent Factory implementation
- Digital twin factory
- CI, dashboards, web UI
- Modifying agent-os taxonomy via curriculum
- Code changes to prototypes/adapters

## Student code rule

Intern track: **no prototype edits** until beginner assessment pass + mentor approval.

## Teacher rule

Do not teach production deployment from this repo.

See [anti-hype-learning-policy.md](anti-hype-learning-policy.md)
