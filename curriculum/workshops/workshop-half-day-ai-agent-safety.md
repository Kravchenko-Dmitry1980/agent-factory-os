# Workshop: Half-Day AI Agent Safety

## Audience

Mixed team — devs, leads, operators.

## Duration

4 hours (with breaks)

## Goal

Full Levels 0–7 sampler: agent basics through evaluation.

## Agenda

| Hour | Module focus | Activity |
|------|--------------|----------|
| 1 | 00–02 Orientation + failures | Demos + anti-patterns skim |
| 2 | 03–06 Safety | fail-closed, approval, memory exercises |
| 3 | 07–09 Workflow + traces | escalation + read trace exercise |
| 4 | 10 Evaluation + discussion | smoke + regression lesson + assessments preview |

## Discussion Questions

1. Where would our real product fail silently?
2. Which gate is weakest today?
3. CI vs local evaluation?

## Expected Learning Outcome

Each participant picks a role track; lead schedules follow-up assessments.
