# Failure-Based Learning

## Principle

Teach from **how systems fail**, not from ideal diagrams only.

## Sources in repo

- `agent-os/09_antipatterns/`
- `prototypes/*/failure-modes.md`
- `observability/examples/` (deny traces)
- `evolution/examples/`

## Exercise pattern

1. Show deny trace or failure mode doc
2. Ask "what gate was removed?"
3. Run demo proving gate present

## Avoid

- Only happy-path success stories
- "Trust the model" framing

## Demo anchor

failed-review-trace.txt — critic pass, human deny.

Lesson: failure teaches that **multiple checks** matter.
