# Practice Before Platform

## Principle

Students must **run and read** small demos before designing frameworks, factories, or shared runtimes.

## Minimum practice bar

- 6 core prototypes run
- 3 deny traces read
- 1 evaluation smoke cycle
- 1 change proposal on paper
- 1 drift identification exercise

## Forbidden shortcut

"Let's build Agent Builder Kit to learn" — Kit comes **after** criteria, not as learning vehicle.

## Teacher enforcement

Redirect framework ideas to exercise-identify-platform-drift.

## Student self-check

Can I explain bypass demo without notes? If no → more practice, less architecture.
