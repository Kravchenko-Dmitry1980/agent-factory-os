# Agent-OS Learning Method

How this curriculum uses the repository as textbook.

## Layers as curriculum spine

```
Doctrine (why) → Patterns (what) → Prototypes (show) → Traces (observe) → Evaluation (check) → Evolution (change)
```

## Rules

1. Never teach doctrine without a demo anchor when one exists
2. Never run demo without reading audit
3. Pair every pattern with an anti-pattern reference
4. Promotion stories stay separate from runtime lessons

## Teacher + student artifacts

| Need | Location |
|------|----------|
| Concept simple | curriculum/lessons |
| Concept deep | agent-os/doctrine |
| Hands-on | curriculum/exercises |
| Daily ops | operator-playbooks |

## Anti-method

- Slide-deck-only training
- Swarm tutorials as architecture
- Model leaderboard as success metric

See [small-steps-method.md](small-steps-method.md)
