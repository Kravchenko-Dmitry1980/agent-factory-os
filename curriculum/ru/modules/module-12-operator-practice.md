# Модуль 12 — Практика оператора

## Цель

Уверенно работать по operator-playbooks: runbooks, troubleshooting, чеклисты.

## Простое объяснение

Оператор — не «промпт-инженер», а человек, который **запускает демо, читает trace, гоняет evaluation** и эскалирует по playbook, не обходя gates.

## Ключевые идеи

- Runbooks для prototypes / integrations / real adapters
- common-errors troubleshooting
- Чеклисты перед изменением
- Связь curriculum ↔ operator-playbooks
