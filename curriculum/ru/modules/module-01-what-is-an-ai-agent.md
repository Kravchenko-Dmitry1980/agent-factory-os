# Модуль 01 — Что такое AI-агент

## Цель

Понять агента как **ограниченный workflow** — не магию, не «личность», не AGI.

## Простое объяснение

**Агент** здесь: получить задачу → вызвать инструменты → при необходимости память → пройти проверки → при необходимости спросить человека → выдать результат. Это программа с **правилами**, не автономный разум.

## Ключевые идеи

- Цикл: думать → действовать → наблюдать → повторить (с лимитами)
- Инструменты расширяют возможности; gates ограничивают вред
- Память должна быть ограничена и проверяема
- Subagent — делегированная подзадача, не «рой» по умолчанию

## Частые ошибки

- Называть агентом любой чат с LLM
- Думать, что больше агентов = лучше
- Снимать лимиты, чтобы демо «стало умнее»
