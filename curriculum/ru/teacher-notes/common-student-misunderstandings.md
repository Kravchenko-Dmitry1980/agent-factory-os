# Типичные заблуждения студентов

| Заблуждение | Правда | Ответ преподавателя |
|-------------|--------|---------------------|
| Exit 0 = безопасно | Может быть Published False | Покажите bypass |
| Критик PASS = факты OK | Критик ≠ verifier | failed-review trace |
| Больше агентов = лучше | Больше gates теряется | Один workflow сначала |
| Прототипы = MVP | Учебная лаборатория | system-positioning |
| Память = знание | Память bounded + verify | overflow demo |
| Smoke = прод | Минимальная планка | regression lesson |
| Phase 3 сейчас | Критерии 8 + lead | phase-3-entry-criteria |
| Промпт починит governance | Gates в коде/trace | accidental-auto-approve |
| LLM JSON = API контракт | Verify отдельно | malformed |
| Evaluation необязателен | Gate на Phase 3 | три скрипта |

## Red flag в классе

Студент хочет «убрать человека для скорости» — остановите занятие, запустите no-approval.

## Правило

Всегда возвращайтесь к **trace**, не к спору о модели.
