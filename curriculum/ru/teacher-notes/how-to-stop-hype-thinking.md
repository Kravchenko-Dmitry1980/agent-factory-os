# Как остановить hype-мышление

## Таблица замен

| Hype | Замена |
|------|--------|
| «Автономный агент» | Workflow с gates |
| «Заменит команду» | Ускоряет черновик, человек на риске |
| «AI-платформа» | Учебная лаборатория |
| «Самообучается» | Change proposal + evaluation |
| «100% точность» | Verify + trace |

## Правило класса

Любое заявление → **какое событие в trace?** Нет события — нет заявления.

## Упражнение

Попросите переписать рекламный абзац продукта в 3 события trace (даже выдуманных, но структурно правильных).
