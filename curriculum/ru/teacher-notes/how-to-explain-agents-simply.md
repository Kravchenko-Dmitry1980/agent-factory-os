# Как просто объяснить агентов

## Скрипт (30 секунд)

«Агент здесь — **рецепт с проверками**: задача → черновик → проверки → человек при риске → результат. Не личность и не AGI.»

## Аналогия

Кухня: повар (LLM), техник (tools), санитарный инспектор (verify), менеджер (human approval).

## Чего избегать

- «Цифровой сотрудник»
- «Думает как человек»
- «Автономный коллега»

## Демо

```powershell
python prototypes/review-loop-agent/minimal-demo.py --scenario happy
```

Попросите назвать 4 коробки на доске: task, critic, human, publish.

## Если спрашивают про swarm

«Swarm без gates — масштабирование ошибок. Сначала один безопасный workflow.»
