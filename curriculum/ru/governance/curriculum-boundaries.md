# Границы curriculum

## В scope

- Структура обучения, модули, упражнения, оценки
- Ссылки на существующие демо и playbooks
- Методика и governance **обучения**

## Вне scope (запрещено в Phase 2.7-RU)

- Новый код, скрипты, CI
- Изменения prototypes/ integrations-real / agent-os / Books
- Agent Factory как «уже готов»
- Production runtime narrative

## Стажёр

Не правит gates до pass beginner assessment (кроме учебных заданий с наставником).

## Языки

Английский curriculum в `curriculum/` — источник структуры; русский — `curriculum/ru/`. Английские файлы не удалять и не переименовывать.
