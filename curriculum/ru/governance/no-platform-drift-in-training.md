# Без platform drift в обучении

## Запрещено как capstone

- Объединить все prototypes в один shared runtime
- Снять approval «для скорости обучения»
- Назвать учебные демо production MVP
- Продвинуть markdown в agent-os без promotion criteria

## Разрешённый capstone

- Smoke PASS (понимая лимиты)
- Один change proposal на бумаге
- Три разобранных deny trace
- Упражнение drift pass
