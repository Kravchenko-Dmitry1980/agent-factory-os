# Целостность оценок

## Разрешено

- Open book (документация, playbooks)
- Повтор упражнений до pass
- Наставник в комнате при практике

## Запрещено

- Подделка smoke (пропуск скриптов, правка ожиданий без proposal)
- Pass без демонстрации bypass / deny
- Подпись phase-3 без 8 компетенций

## Fail

Fail = план обучения, не наказание. Фиксируйте пробелы в learning log.

## Смена состава команды

При смене lead/architect — re-review phase-3 gate.
