# Старт для студента

## 4 шага

1. Прочитайте [../README.md](../README.md) (5 мин)
2. Пройдите [../../operator-playbooks/start-here/first-30-minutes.md](../../operator-playbooks/start-here/first-30-minutes.md) (hands-on)
3. Откройте [../course-map.md](../course-map.md) — уровень 0
4. Выберите трек: [../role-based-tracks/](../role-based-tracks/)

## Ежедневная привычка

- Одно упражнение или один deny-сценарий
- Запись в [student-learning-log-template.md](student-learning-log-template.md)
- Вопрос наставнику с **кусочком trace**, не «оно не работает»

## Чего не делать в первую неделю

- Правки gates «для скорости»
- `--real` без разрешения
- Чтение Books/ вместо curriculum
- Обещания «сделаем фабрику агентов»
