# Глоссарий студента

| Термин | Простое значение |
|--------|------------------|
| Агент | Workflow с инструментами и правилами, не «личность» |
| Gate | Проверка, которая может остановить действие |
| Fail-closed | При сомнении — стоп, не «попробовать» |
| Trace | След выполнения: события, gates, исходы |
| Critic | Редактор черновика, не проверка фактов |
| Verification | Проверка перед доверием/публикацией |
| Human approval | Явное разрешение человека |
| Bounded memory | Память с лимитом и записью после verify |
| Escalation | Передача человеку после лимита retry |
| Rollback | Откат изменения к безопасному состоянию |
| Platform drift | Уход в «большую платформу», ослабление gates |
| Smoke | Быстрая проверка, что демо ещё живы и безопасны |
| Regression | Безопасное поведение сломалось после изменения |
| Evaluation | Проверка поведения (не оценка IQ модели) |
| Governance | Правила управления: знание + runtime gates |
| Mock | Учебный режим без реального внешнего API |
| Phase 3 | Agent Builder Kit — после критериев |
| Operator playbook | Ежедневные инструкции оператора |
| Change proposal | Документ перед изменением системы |
| Deny | Отказ с причиной в trace |

При первом упоминании английского термина — одно предложение по-русски (см. уроки).
