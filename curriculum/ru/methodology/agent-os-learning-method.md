# Метод обучения Agent-OS

## Позвоночник курса

```
Доктрина → Паттерны → Прототипы → Trace → Evaluation → Evolution
```

**Нельзя** читать только doctrine без демо — студент не видит gate.

## Правила

1. Один слой за занятие
2. Каждый принцип = хотя бы один deny trace
3. Книги (Books/) — справочник, не первая неделя
4. Promotion в agent-os — не цель стажёра

## Для преподавателя

Hook → имя → trace → упражнение → checkpoint.
