# Обучение: сначала безопасность

## Порядок приоритетов

1. **Safe** — deny работает, trace честный  
2. **Understandable** — студент объясняет gate  
3. **Correct** — факты и бизнес-логика  
4. **Fast** — скорость последняя  

## Практика

Сначала no-approval, потом happy. Сначала malformed LLM, потом happy.

## Антипаттерн обучения

«Сначала сделаем красивый UI / swarm, потом добавим approval» — **запрещено** в curriculum.
