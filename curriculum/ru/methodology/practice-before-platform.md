# Практика до платформы

## Минимальная планка перед разговором о «платформе»

- [ ] 6+ разных демо запущены осознанно
- [ ] 3+ deny trace разобраны
- [ ] 1 smoke PASS (и понимание лимитов smoke)
- [ ] 1 change proposal (бумага)
- [ ] 1 упражнение platform drift pass

## Что не считается практикой

- Общий `shared/runtime.py` для всех демо на capstone
- Презентация без команд
- «Мы используем Cursor — значит платформа есть»

## Capstone обучения

Smoke + proposal + traces — **не** «объединить всё в Agent Factory».
