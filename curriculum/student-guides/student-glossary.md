# Student Glossary

Simple definitions — read when a word appears.

| Term | Meaning |
|------|---------|
| **Agent** | Workflow that uses tools/model with checks — not a conscious being |
| **Gate** | Checkpoint that allows or blocks progress (verify, approve) |
| **Fail-closed** | If unsure → deny |
| **Verification** | Check against rules/tests/structure — not "sounds good" |
| **Approval** | Human explicitly allows high-impact action |
| **Critic** | Advisory reviewer — not final truth |
| **Trace** | Ordered log of events explaining decisions |
| **Audit** | Record of actions for accountability (append-only ideal) |
| **Escalation** | Stop automation; human must take over |
| **Retry** | Try again after failure — bounded count |
| **Regression** | Safe behavior broke after a change |
| **Rollback** | Revert to last known-good state |
| **Platform drift** | Demos become accidental framework; gates weaken |
| **Prototype** | Small teaching demo ~200 lines — not production |
| **Adapter** | Real I/O boundary (LLM, Telegram) — still local/mock default |
| **Doctrine** | Core beliefs in agent-os/doctrine |
| **Promotion** | Governed path for ideas into agent-os curated layer |
| **Smoke check** | Quick local demo script PASS/FAIL — not full QA |
| **Phase 3** | Agent Builder Kit — only after entry criteria |
