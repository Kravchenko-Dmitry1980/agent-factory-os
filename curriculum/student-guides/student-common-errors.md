# Student Common Errors

| Problem | Fix |
|---------|-----|
| python not found | Install Python 3.12+; use `py -3.12` |
| ModuleNotFoundError prototypes | `cd` to repo root |
| Invalid --scenario | Read demo file choices or student-command-list |
| Expected FAIL in exercise | Some demos should deny — read exercise pass criteria |
| Trace doesn't match demo | Map via canonical-events.md |
| Smoke FAIL after your edit | Rollback; see exercise-decide-rollback |
| Overwhelmed by repo size | Follow course-map level by level — not Books/ first |
