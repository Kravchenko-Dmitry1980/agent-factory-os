# Module 13 — Phase 3 Readiness

## Goal

Know **when** Agent Builder Kit is safe to start — and when it is not.

## Simple Explanation

Phase 3 builds tools to compose agents **using** this methodology. Starting Phase 3 without operators who understand gates repeats industry mistakes at larger scale.

## Key Ideas

- Phase 3 ≠ automatic next step
- Entry criteria are human-verified competencies
- Agent Factory is not this curriculum
- Digital twins factory waits behind Builder Kit discipline

## Exercise

Complete phase-3-readiness assessment with lead sign-off.

## Common Mistakes

- "We read the docs" without running demos
- Jumping to framework because Phase 2 feels complete
- Marketing Agent Factory before criteria met

## Checkpoint Questions

1. List five Phase 3 entry criteria.
2. Why is platform drift a blocker?
3. What is Agent Builder Kit *not*?

## Expected Outcome

Student and lead agree: ready / not ready / ready with conditions — documented.
