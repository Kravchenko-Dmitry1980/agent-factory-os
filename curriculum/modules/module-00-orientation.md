# Module 00 — Orientation

## Goal

Know what this repository is, who it is for, and what it explicitly is **not**.

## Simple Explanation

This repo is a **learning lab** for safe AI workflows — not software you deploy to customers. It combines written principles (agent-os), small demos (prototypes), and operator guides.

## Key Ideas

- Governance-first knowledge system
- Small demos teach gates; platforms hide them
- Phase 3 (Agent Builder Kit) comes **after** learning, not before
