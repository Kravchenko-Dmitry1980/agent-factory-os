# Operator Need — Free-Form CLI (RU)

**Дата:** 2026-05-26  
**Статус:** PLAN_ONLY

---

## Проблема

Demo Runner v0.1 уже даёт:

- меню из 15 пунктов
- русское резюме
- объяснение TRACE
- статус безопасности

Но оператор **не может ввести свою задачу**. Можно только выбрать frozen сценарий (`happy`, `missing_approval`, …).

Из-за этого система ощущается как **набор тестов**, а не как агент, с которым можно «поговорить» в контролируемой лаборатории.

---

## Что нужно

Минимальный режим **free-form CLI**:

```text
Введите текст задачи:
Подготовить короткий текст для заказчика о статусе проекта

Режим:
1. Safe mock/default
2. Local provider (только явно)

→ безопасный разбор результата:
  - что произошло
  - какое решение (DELIVERED / BLOCKED / ESCALATED / FAILED / NEEDS_APPROVAL)
  - почему заблокировано или не доставлено
  - какие safety gates сработали
  - ключевые TRACE события
```

**Один запуск — одна задача.** Без чата, без памяти, без публикации.

---

## Почему это важно

| Сейчас | После free-form CLI (план) |
|--------|----------------------------|
| «Выберите сценарий 1–15» | «Введите свою задачу (безопасный demo-текст)» |
| Доказывает frozen paths | Доказывает gates на произвольном **lab-safe** вводе |
| Хорошо для обучения по сценариям | Лучше для ощущения «агент слушает задачу» |

---

## Что это **не** решает

- Не делает продуктовый чат
- Не заменяет Operator Console
- Не даёт real human approval UI
- Не сохраняет историю сессий
- Не выполняет реальные действия (отправка, файлы, API)

---

## Связь с Demo Runner

Demo Runner v0.1 **остаётся frozen** — меню сценариев и baseline checks.

Free-form CLI — **отдельный** entry point для custom input. См. [IMPLEMENTATION_OPTIONS.md](IMPLEMENTATION_OPTIONS.md) — Option B recommended.

---

## Критерий успеха (для будущей impl)

Оператор может:

1. Ввести короткий synthetic/demo текст задачи
2. Увидеть русское объяснение и gates
3. Понять, почему результат доставлен или заблокирован
4. Не вызвать провайдер и не выполнить внешнее действие по умолчанию
