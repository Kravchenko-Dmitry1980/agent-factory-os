# Agent Factory vs Learning Lab

Simple positioning for stakeholders and students.

---

## Learning Lab (what we have now)

**Purpose:**

- Teach safe AI workflow design
- Explore failures in small demos
- Fail safely with visible gates
- Understand behavior through traces

**Artifacts:** prototypes, playbooks, curriculum, evaluation scripts (local), doctrine.

**Not:** customer-facing product, autonomous platform, hosted runtime.

---

## Agent Builder Kit (Phase 3 starts here)

**Purpose:**

- Package **reusable agent templates** (specifications)
- Encode safe patterns as checklists
- Help teams **design** real agents without starting from hype

**Artifacts (v0.1):** MD templates — workflow, gates, memory, evaluation, trace, change proposal.

**Not:** code generator by default, factory, SaaS.

---

## Agent Factory (much later)

**Purpose:**

- Generate agent systems **repeatedly** from templates
- Stronger governance, evaluation UX, registry, versioning
- Possibly integration with production adapters

**Requires:** Builder Kit discipline proven, team assessments, no platform drift history.

---

## Timeline (conceptual)

```
Now          Phase 3.0           Phase 3.x+          Future
Learning Lab → Builder Kit v0.1 → More templates → Factory (optional)
                                      ↓
                               Digital twin factory (much later)
```

## Messages that prevent hype

| Wrong | Right |
|-------|-------|
| «We built an AI platform» | «We built a learning lab with gated demos» |
| «Phase 3 = launch» | «Phase 3 = template specs» |
| «Agents are autonomous» | «Agents are workflows with human gates» |
