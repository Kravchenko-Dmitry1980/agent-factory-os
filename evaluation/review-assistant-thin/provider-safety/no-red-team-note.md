# No Red-Team Platform Policy — Phase 3.4 Provider Safety

This harness is **not** a red-team or exploit platform.

---

## Explicitly excluded

- No exploit library
- No attack corpus generation
- No dynamic prompt mutation
- No harmful executable instructions
- No real data exfiltration attempts
- No automated adversarial campaign runner

---

## What we use instead

- 16 fixed synthetic safety cases
- Harmless placeholder text only
- Deterministic string-pattern classification
- Local PASS/FAIL assertions
