# Event Taxonomy

Canonical **conceptual** workflow events for governed agent systems.

This is a vocabulary for humans and postmortems — **not** a telemetry schema platform.

## Start Here

- [canonical-events.md](canonical-events.md) — required event list
- [severity-levels.md](severity-levels.md) — how to prioritize
- [event-lineage.md](event-lineage.md) — how events chain
- [anti-pattern-events.md](anti-pattern-events.md) — events that should NOT exist

## Usage

When adding a prototype or adapter demo, name audit actions to align with canonical events where possible.

Do not deploy a central event bus to enforce this taxonomy.
